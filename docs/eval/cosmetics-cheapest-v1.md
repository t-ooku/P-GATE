# 化粧品 評価セット v1（最安案内）

目的：同一商品判定の正確さと、2 店以上の実価格を比べられた割合を、**別々に**測る。対象を減らして成功率を高く見せない（20 商品は固定。比べられなかった商品も分母に残す）。

## 根拠の種類（列「確認」）
- **記録**：D1 `price_observations`（2026-11-07〜11-14）の商品名・商品キー・価格を Cowork が読んだ。商品ページは開いていない。
- **ページ**：販売先の商品ページを開いて、色番・容量・JAN・商品状態を確かめた。**v1 ではまだ 0 件。**
- **未確認**：まだ何も確かめていない。

「記録」だけの行は、正解として採点に使わない（候補）。「ページ」になった行だけを正解にする。

## 採点のしかた（Codex が C-1 の前後で測る）
- **同一商品判定**：各商品について、仕組みがまとめた楽天・Yahoo! のページを、この表の「同じ商品」「紛らわしい別商品」と突き合わせる。
  - 誤った同一視（別商品をまとめた）＝ 1 件でも公開を止める。
  - 取りこぼし（同じ商品をまとめられなかった）は件数で報告。
- **比較成立率**：20 商品のうち、条件を満たす実オファー（#757 の条件）が 2 店以上そろった商品の数。分母は常に 20。
- 「記録」だけの行は採点に使わない。「ページ」で確かめた行だけ。確かめた行が少ないうちは「正解 n/20 で測った」と書く。
