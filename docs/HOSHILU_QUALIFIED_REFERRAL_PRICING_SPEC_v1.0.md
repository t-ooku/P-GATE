# HOSHILU 価格連動型・有効送客課金仕様 v1.1

更新日: 2026-07-30

注文追跡を前提とせず、送客時点で検証できた商品価格にジャンル料率を掛ける。
これは売上成果報酬ではなく「価格連動型の有効送客料」である。

## 計算式

`送客料 = clamp(表示商品価格 × ジャンル料率, 最低額, 上限額) × プラン倍率`

- 1円未満は切り上げる。
- 価格、通貨、取得日時、出品ID、Seller ID、クリックIDを監査記録へ保存する。
- 価格を確認できない場合は課金しない。
- 税・送料の扱いはモールごとに統一し、原則として画面に表示した税込商品価格を使う。

## Amazon等で同じ商品へ複数セラーが重なる場合

商品ではなく、`モール + 商品ID + バリエーションID + Seller ID + Seller SKU`
を一つの出品として扱う。

1. 在庫・価格・セラー固有URLを検証する。
2. 検索条件、バリエーション、契約状態を判定する。
3. 対象出品の中でプラン、総支払額、配送条件、品質を使って表示順を決める。
4. 同条件なら公平にローテーションする。
5. クリック時に送客先セラーを一社へ確定する。
6. 実際に選択された一社だけを課金する。複数社へ分配課金しない。

通常のASINページなど、遷移後にカート獲得セラーが変わり得るリンクは
契約セラー固有の送客として課金しない。セラー固有のオファーURL、
ストアURLまたは検証済み出品URLでSeller IDを維持できる場合だけ課金する。

## 有効送客

以下をすべて満たす一件だけを課金する。

- HOSHILUの商品カードから発生
- 契約中セラーの販売中商品
- 表示価格を送客直前に検証済み
- 署名付きクリックIDが有効
- 人間の操作と判定
- 同一利用者・商品・セラーは24時間に一回
- 運営・セラー自身のテストではない
- 転送先が正常応答
- 転送先が対象Seller IDに固定されている
- 課金対象Seller IDとオファーSeller IDが一致

検索結果表示、URLエラー、価格欠落、Seller ID不一致、セラーを固定できない
汎用モールリンクは課金しない。
