# HOSHILU 全カテゴリ横断モール拡張計画

更新日: 2026-07-30

## サービス定義

HOSHILUはファッション検索サービスではない。

> 名前が分からない、検索語にできない、どこで買えるか分からない商品を、
> 曖昧な記憶から見つける全カテゴリの商品発見サービス。

## モール構造

### 常設する主力4モール

1. Amazon
2. 楽天市場
3. Qoo10
4. SHEIN

検索・SNS・ランディングページでは、この4モールをHOSHILUの基本横断先として
一貫して訴求する。

### カテゴリ別に追加する専門モール

専門モールは全商品へ一律表示せず、検索カテゴリと出品確認結果に応じて追加する。

| カテゴリ | 追加候補 | 主な役割 |
|---|---|---|
| ファッション | ZOZOTOWN、SHOPLIST、MUSINSA、BUYMA | 日本・韓国・海外ブランド |
| 家電・ガジェット | Yahoo!ショッピング、ヨドバシ.com、ビックカメラ.com | 型番・国内在庫・周辺機器 |
| コスメ・美容 | @cosme SHOPPING、マツキヨココカラ、LOFTネットストア | 国内コスメ・韓国コスメ・美容雑貨 |
| 生活雑貨・インテリア | ニトリネット、無印良品ネットストア、LOHACO | 家具・収納・日用品 |
| 食品・海外商品 | Yahoo!ショッピング、成城石井.com、各輸入食品店 | 海外食品・地域商品 |
| ホビー・推し活 | 駿河屋、あみあみ、アニメイト通販 | グッズ・フィギュア・限定商品 |
| ベビー・キッズ | アカチャンホンポ、トイザらス、各総合モール | 育児用品・玩具 |
| ペット | PETEMO、チャーム、各総合モール | ペット用品・消耗品 |
| スポーツ・アウトドア | Alpen Online、スポーツデポ、各ブランド公式 | 用具・ウェア・アウトドア |

候補名は接続を保証するものではない。API、商品フィード、利用規約、検索URL、
アフィリエイト条件を確認できた順に接続する。

## 表示原則

### 商品カード

- 確認済みの商品詳細URLだけ「○○で見る」と表示
- 検索結果URLを商品詳細URLとして扱わない
- 在庫・価格・商品同一性の鮮度を記録
- 商品画像の取得元と購入先を別々に管理

### 出品URLがない場合

- 「全部のモールで探す」を表示
- 主力4モールの横断検索へスクロール
- カテゴリ判定済みなら専門モール検索も追加
- 「出品あり」とは表現しない

## 優先順位

### Phase 1: 信頼を作る

- 主力4モールの商品詳細URL率を上げる
- 検索語の一語欠落を防止
- 商品画像取得元と購入URLの関係を可視化
- URL検証日時と失効理由を診断可能にする

### Phase 2: カテゴリを広げる

- ファッション専門4モール
- 家電・コスメの専門モール
- 生活雑貨・ホビー・食品
- ベビー・ペット・スポーツ

### Phase 3: 日本の需要データを蓄積する

- 見つからなかった検索を匿名集計
- ほしっトク保存と再検索を接続
- 商品リクエストを検索辞書へ反映
- ジャンル別の検索完了率と購入先遷移率で接続優先度を更新

## 日本で勝つための評価指標

最重要:

`商品名が分からない状態 → 候補発見またはほしっトク保存`

運用指標:

- 主力4モールの商品詳細URL付与率
- カテゴリ別の検索完了率
- 「全部のモールで探す」利用率
- 商品詳細遷移率
- ほしっトク保存率
- 7日・30日再訪率
- 未発見検索が後日発見へ変わった割合
