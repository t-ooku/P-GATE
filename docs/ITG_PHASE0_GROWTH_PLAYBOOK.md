# MYGATE × ITG Phase0 無料集客・広告運用プレイブック

## 目的

ITGが米国Amazonから仕入れる並行輸入商品を起点に、MYGATEの実証ユーザーを獲得する。初期段階では広告費を使わず、SEO・SNS・コミュニティ・LINE導線で検索、保存、商品ページ遷移を検証する。

## 優先ペルソナ

1. 日本在住で英語・中国語・韓国語を主に使う外国人
2. 米国限定品、日本未発売品、並行輸入品を探す日本人
3. 米国フィギュア・コレクター商品を探す人
4. 日本で使える米国の小型電化製品を探す人
5. 名前や適合条件が分からない小型車パーツを探す人

## 価値提案

- 商品名が日本語で分からなくても、用途・形・記憶から探せる
- 日本語・英語・中国語・韓国語で相談できる
- 米国商品を日本国内の販売ページで確認できる
- 見つからない要望をMYWISHに残し、需要として蓄積できる
- 価格・在庫・適合性は販売ページの最新情報で再確認させる

## SEOクラスター

### 米国限定・並行輸入

- アメリカ限定 商品 日本で買う
- 日本未発売 アメリカ 商品
- 米国 Amazon 商品 日本 購入
- 並行輸入品 探し方
- 海外の商品 名前がわからない

### フィギュア・ホビー

- アメリカ限定 フィギュア
- 海外版 フィギュア 日本で買う
- キャラクター名がわからない フィギュア
- 昔見た おもちゃ 探す

### 小型家電

- アメリカ家電 日本で使える
- 120V 家電 日本 使用
- 海外家電 変圧器 必要
- 米国プラグ 日本 対応

安全上、電圧・周波数・プラグ・技適・PSE等は断定せず、型番と販売ページを確認させる。

### 車パーツ

- 車 パーツ 名前がわからない
- アメリカ車 小さい部品
- 車種 年式 適合 パーツ 探す
- 内装 隙間 パーツ 名前

適合保証はせず、車種・年式・型式・左右・寸法の確認を必須にする。

## SNSコンテンツ柱

1. 「これ何て名前？」クイズ：曖昧な写真・用途からMYGATEで探す
2. 「日本で使える？」検証：米国家電の電圧、プラグ、規格確認
3. 「米国限定」発見：フィギュア、ホビー、生活雑貨
4. 「小さな車パーツ」解決：用途から部品名へたどり着く
5. 在日外国人向け：英語・中国語・韓国語で日本国内購入を支援

## 初期チャネル

- X：短い「名前が分からない」課題、検索例、入荷・値下げ告知
- Instagram / TikTok：15〜30秒のビフォー・アフター検索動画
- YouTube Shorts：用途説明から候補3件までの画面録画
- LINE：再訪、MYWISH、MYWATCH通知の中心
- Facebook Groups / 外国人コミュニティ：英語中心。各グループ規約を守り宣伝投稿の許可を得る

## 30日運用

- 月・木：米国限定フィギュア
- 火：小型家電の規格確認
- 水：名前が分からない車パーツ
- 金：英語・中国語・韓国語の在日生活投稿
- 土：ユーザー投票「どれを探してほしい？」

## 有料広告を始める条件

有料出稿は、各言語で最低100セッションを集め、検索成功率と商品ページ遷移率を確認してから行う。広告費、アカウント、日予算、地域、配信期間は責任者の明示承認後に設定する。最初は検索広告より、商品発見体験を見せる短尺動画の小額テストを優先する。

## 禁止・注意

- 「最安値」「必ず使える」「必ず適合」「正規品」を根拠なく断定しない
- Amazon等の商標・画像・レビューを許可なく広告素材へ転載しない
- 医療、電気安全、車両適合は専門家やメーカー確認の代替にしない
- 在日外国人を一括りにせず、言語別の反応でコピーを改善する
