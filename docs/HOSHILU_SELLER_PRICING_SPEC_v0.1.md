# HOSHILU Seller Pricing Spec v0.1

## 原則

HOSHILUは、すでに存在する需要を契約商品へ接続し、実際の成果と高度な需要分析に対して課金する。支払額を検索順位へ使用しない。

## 基本モデル

| 項目 | 料金方針 |
|---|---|
| 商品登録・商品フィード同期 | 無料 |
| 基本HOSHILU INSIGHT | 無料 |
| HOSHILU経由と確認できた送客・注文 | 契約別の成果報酬 |
| 詳細需要分析・トレジャーMAP | 有料オプション |
| 定期通知・需要レポート | 有料オプション |
| 検索順位の購入 | 提供しない |

成果報酬率、月額、無料期間、上限額はコードへ固定せず、契約レコードで管理する。

## 順位

契約商品は関連性を満たす場合に非契約商品より優先できる。ただし、関連性、在庫、顧客総額、配送条件を無視して上位表示してはならない。広告費・契約料金・利益額は関連性順位へ使用しない。

## パイロット

初期セラーには商品同期と基本INSIGHTを無料提供する。成果報酬は、HOSHILUの署名付きリンクまたは合意済み注文照合で帰属確認できた成果だけを対象にする。
