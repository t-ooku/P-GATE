## 運用上の表記

- ブランド名は `MYGATE`（スペースなし）で統一する。
- ITGアカウントはITグループ株式会社の公式承認を得てから「公式」と表記する。
- Amazon、楽天等の第三者ロゴをプロフィール画像へ入れない。
- 商品紹介に広告・アフィリエイト関係がある場合は、必要な `広告` / `PR` 表記を行う。
