# HOSHILU 注文帰属・成果報酬判定ポリシー v1.0

更新日: 2026-07-30

## 原則

HOSHILU経由であることを証明できた注文だけをセラー成果報酬の対象にする。
離脱後の直接購入、別端末での購入、別リンク経由の購入を推測で請求しない。

## 計測フロー

1. 商品の「○○で見る」を押す
2. HOSHILUが署名付きクリックIDを発行
3. `/go` がクリックID、セラー、商品、時刻を匿名記録
4. 検証済み商品詳細URLへ転送
5. 契約セラーまたはモールの許可された仕組みが注文成果を返す
6. クリックID、注文ID、商品ID、帰属期間、返品状態を照合
7. 証明できた成果だけ前払い残高から消化

## 三段階の成果

### 1. VERIFIED SELLER ORDER

セラー成果報酬を請求できる。

- HOSHILU署名付きクリックIDが有効
- セラー側の署名済み注文Webhookまたは合意済み注文照合がある
- 注文の商品IDがクリックした商品または許可された同一商品に一致
- 帰属期間内
- 同じ注文IDが未計上
- キャンセル・返品分を控除済み

### 2. MARKETPLACE AFFILIATE CONVERSION

モールのアフィリエイト成果として記録する。

- Amazon、楽天等の公式レポートで成果確認
- モールの規約と帰属期間に従う
- 同じ注文へセラー成果報酬を重ねて請求しない
- 個別ユーザーをサブタグ等で追跡しない

### 3. ASSISTED / CLICK ONLY

販促KPIには使うが、成果報酬を請求しない。

- HOSHILUから商品ページへ遷移しただけ
- 後日、モールを直接開いて購入した可能性がある
- 別端末・別ブラウザで購入
- 注文WebhookにクリックIDがない
- 注文商品との一致を証明できない

## 離脱後の直接購入

ユーザーがHOSHILUを離れ、後日モールへ直接ログインした場合:

- モール側の公式アフィリエイト判定が残っていれば、そのレポートを正とする
- 契約セラーが、利用者の同意を得た自社アカウント内でクリックIDを注文へ安全に
  引き継げる場合は、署名済み注文照合を利用できる
- どちらもない場合はHOSHILU成果と断定しない

## 二重請求防止

同一注文ID・同一商品明細は一つの収益区分だけへ登録する。

優先順位:

1. 契約で定義されたVERIFIED SELLER ORDER
2. MARKETPLACE AFFILIATE CONVERSION
3. ASSISTED / CLICK ONLY

Amazon等の規約が同じトラフィックでの二重報酬を禁止する場合は、そのモール規約を優先し、
セラー成果報酬を請求しない。

## プライバシー

- 指紋採取で別端末ユーザーを推定しない
- Amazon等のサブタグを個人単位で動的発行しない
- モールのログインID、パスワード、購入者氏名を取得しない
- 注文照合にはハッシュ化した注文参照、商品ID、金額、状態、日時だけを使う
- クリックIDは期限を設定し、用途外利用しない

## モール別の扱い

- Amazon: 公式の特別リンクとアソシエイトレポートを正とする
- 楽天市場: 公式アフィリエイトURLと公式レポートを正とする
- Qoo10・SHEIN: 利用可能な公式アフィリエイト／パートナーレポートを確認できた場合だけ使用
- 契約セラー直販: HOSHILUクリックIDを署名済み注文Webhookで返す

各モールの帰属期間はHOSHILUが一律30日に上書きせず、契約・公式規約の短い方を採用する。
