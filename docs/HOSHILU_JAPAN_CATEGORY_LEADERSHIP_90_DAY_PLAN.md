# HOSHILU 日本カテゴリ第一想起 90日計画

## 勝つカテゴリ

最初の第一想起を「SNSで見た、名前の分からない服を探すならHOSHILU」に固定する。
価格比較ではなく、曖昧な記憶から商品候補と購入可能なモールを見つける体験で勝つ。

## 0〜30日

- 主力8モールの横断検索を完成
- 韓国系・Y2K・海外ガールなど若者語の検索辞書を実装
- 色、形、丈、素材、サイズ、予算を追加質問へ変換
- 商品詳細URL確認済みモールだけ「○○で見る」
- 商品リクエストと、ほしっトク保存を接続
- Instagram音入りリール週3、X動画週4、検索クイズ週3
- 日英SEOに韓国ファッション・名前不明ファッションのページを追加

## 31〜60日

- 検索結果から正解・不正解を匿名で改善できる導線
- 色・サイズ別の在庫鮮度
- ZOZO、SHOPLIST、MUSINSA、BUYMAの商品詳細フィード・提携可否を確定
- 人気の曖昧検索と、ほしっトク商品をSNS・SEOへ再利用
- 在日外国人向け英語検索事例
- クリエイター候補とUGC企画を準備（連絡・報酬は承認後）

## 61〜90日

- 「これ何て検索する？」投稿をシリーズ化
- 商品リクエスト回答を48時間以内にコンテンツ化
- 指名検索、検索完了、保存、再訪、モール遷移を週次改善
- 勝率の高い系統へSEOページを展開
- 有料検索広告はオーガニック勝ちパターン確定後、予算承認を得て小額検証

## 北極星指標

`名前が分からない状態で訪問したユーザーが、商品候補を見つけるか、ほしっトクへ保存した割合`

補助指標:

- 曖昧検索完了率
- 商品詳細ページ遷移率
- ほしっトク保存率
- 7日再訪率
- 検索クイズからの検索開始率
- 確認済み商品詳細URL率
- 誤カテゴリ率

## やらないこと

- モール数だけを競わない
- 未確認の検索URLを商品詳細URLとして表示しない
- 広告料で検索順位を変えない
- 権利不明の画像・音源を使わない
- 若者向け表現を大量の不自然なハッシュタグで損なわない
