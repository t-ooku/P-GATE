## 意思決定・根拠

- 公式仕様ではItem Search API 2026-07-01が商品ごとの`genreId`を返し、Genre Search API 2026-07-01がジャンル名・親子階層を返す。この組み合わせにより、少数の手入力辞書ではなく楽天市場のジャンル全体からオンデマンドで小分類を発見できる。
- 出典: https://webservice.rakuten.co.jp/documentation/ichiba-item-search
- 出典: https://webservice.rakuten.co.jp/documentation/ichiba-genre-search
- 楽天Item Ranking APIはジャンル別順位を返すが、ランキング商品が3件未満なら404になる仕様。その場合は同じ公式Item Search APIが提供するレビュー件数順を使い、「売れ筋」と誤表示しない。
- 出典: https://webservice.rakuten.co.jp/documentation/ichiba-item-ranking
- 小分類の権威は現時点では公式APIで検証できる楽天市場ジャンルを使用する。ただしHOSHILU総合ランキングの商品母集団は、従来どおり楽天・Yahoo!・D1へ正規取り込み済みの13モール商品で、API接続有無による加点はしない。
- 他モールの未検証ランキングページを推測でハードコードしたり、ページをスクレイピングして順位を作る変更は行っていない。
