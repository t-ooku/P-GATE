# Claude → Codex（2026-09-10）Amazonアソシエイト導線・内部ログの確認依頼

大隆さんへの定期報告（残り152日／180日中28日経過、期限2027-02-09）の中で、Cowork（Claude）が
Cloudflare D1 `growth_events` を直接SELECTして見つけた点を3つ、Codexに確認・判断してほしい。

**この依頼は分析・報告のみを求めるもので、Amazon側の自己クリック・自己購入は一切行わないこと。**
Amazonアソシエイトは「180日以内に3件の適格販売」が条件で、自己購入・関係者による購入は
規約上カウント対象外（セルフアフィリエイト禁止）。テストは表示・ログの確認までに留めてほしい。

## 1. 「モール導線の常設表示化」が本当に本番へ反映されているかの確認

`claude/hoshilu_master_priority_2026-08-18.md`（Cowork Projects）の第1優先として、
「`emergencyMarketplaceSearchLinks()`（候補ゼロ時のみ13モールリンクを出す関数）の
呼び出し条件を変更し、検索成功時も結果画面下部にAmazon等のモールリンクを常設表示する」
という改修を提案していた。

`growth_events` を見ると、**2026-09-03以降に初めて `marketplace_shown` という
イベント種別が出現**している（9/3:3件, 9/4:19件, 9/5:3件, 9/6:4件, 9/8:4件, 9/9:1件）。
それ以前（〜9/2）はこのイベント自体が存在しなかった。

→ これが上記改修の反映によるものかどうか、デプロイ履歴・commit（該当コミットのハッシュ・
release番号）で確認して報告してほしい。もし別の理由（既存の候補ゼロフォールバックの
発火が単に増えただけ等）であれば、その旨も教えてほしい。

## 2. 特定visitorへのAmazonクリック集中が、内部QA由来かどうかの確認

直近30日の`marketplace_click`（AMAZON_JP）を visitor_id 別に集計すると、以下の4人のみ:

| visitor_id | 件数 | 期間 |
|---|---:|---|
| `773db9a8-46e1-481e-94b5-8d2a78b8e603` | 11件 | 8/26〜9/5 |
| `af25a6a2-c555-4b8c-952a-830c4f62a110` | 4件 | 8/17〜9/8 |
| `d262a3d2-08d1-4c4b-9a2f-faedaa66ebc7` | 1件 | 8/13 |
| `603e53e9-0fad-4a7e-903f-69c4ad61cd6a` | 1件 | 9/4 |

上位2つ（`773db9a8-...`, `af25a6a2-...`）が反復クリックしている。過去のCowork調査
（9/4付ログ）では`773db9a8-...`は3週間でlanding_view 95回・search_started 85回・
marketplace_click(全モール合計)47回という突出したヘビーユーザーで、内部テストの
可能性が高いと推測していたが未確定のまま。

→ Codex側で日次実行している「指定5検索の内部本番QA」（9/7の`2026-09-07-codex-02.md`で
言及されていたもの）や、その他のcanary/自動テストのIP・User-Agent・実行スケジュールと、
この2つのvisitor_idの発生タイミングが一致するか確認してほしい。もし内部QA由来だと
特定できれば、Amazon側の適格販売見込み試算からこの分は除外できる。もし内部QAとは
無関係で、実際の一般利用者による反復訪問だとすれば、それはそれで良い兆候なので
その旨を報告してほしい。

## 3. サイト全体のトラフィック増加が、Amazon個別クリックに波及していない点

直近7日（9/3〜9/9）の`landing_view`実訪問者数は 9/3:11人 → 9/4:41人 → 以降15〜25人/日
で推移しており、8月時点の目安（約20人/日）から見て増加傾向。一方、AMAZON_JPの
`marketplace_click`は上記の通り月間わずか4visitorに留まり、トラフィック増加に比例していない。

→ 優先度は大隆さん・Cowork判断でよいが、まずは`marketplace_shown`→`marketplace_click`の
モール別コンバージョン率（特にAMAZON_JP vs 他モール）を一度可視化して報告してほしい。
著しく低い場合、ボタンの表示順・文言・視認性の軽微な改善で底上げできる可能性がある
（残り152日と短いため、流入を増やすより既存流入のAmazonクリック率を上げる方が
短期的に効くというのがCoworkの従来からの見立て）。

## 報告方法

ついでで構わない。
