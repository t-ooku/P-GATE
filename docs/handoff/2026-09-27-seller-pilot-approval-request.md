# 承認依頼：新規外部Seller検証経路

## 承認が必要な変更（まだ実行していない）
対象は今回の検証で初めて契約する外部店舗。社内・関連会社・テスト、既存の有料契約、既存無料期間は変更しない。

1. D1追加migration 0087（営業許諾証跡）、0088（問い合わせ通知状態）、0089（限定見本・公開承認・本人確認・保存商品）。既存未適用分の一括適用はしない。直前にd1_migrationsとの突合が必要。
2. `SELLER_MANUAL_PILOT_ENABLED=true`：管理者が保存済み相談から限定見本を作成し、相談メール本人の会員ログインだけに閲覧・承認を許可する。
3. `SELLER_PILOT_OFFER_VERSION=external-seller-calendar3-v1`：公開開始時刻（JST）から暦3か月。同日が存在しない月は末日、時刻は同じ。例：1月31日12:30→4月30日12:30。90日ではない。
4. 支払い方法不要。体験中・終了時にStripe顧客・請求書・subscription・決済を作らない。通常料金は月額4,980円（税込）のまま。終了後の継続は本人の別途明示同意と既存決済側の確認が必要。現実装は自動有料化しない。継続相談は担当者へ。
5. 期限後は公開ページ・横断検索から除外（404）。管理画面・KPI・承認監査・保存履歴は維持。保存画面に掲載終了を表示し、終了したページへの購入導線を出さない。データの自動削除は追加しない。保管期間は既存のプライバシー・問い合わせ対応に従い、別の削除申請は担当者対応。
6. 管理者の手動公開は店舗承認後のみ。商品変更は公開前の見本へ戻し再承認する。現在の公開後の商品更新は409で止める（担当者レビューが必要）。表示順位に優遇なし。

## 未確認の解消に必要なログイン
- Gmail：wranglerの `SELLER_INQUIRY_NOTIFY_EMAIL` と同じアカウントを接続する。現在の接続は別アカウント。https://mail.google.com/ で右上のアカウントを確認。別の受信箱で返信0と判断しない。
- 管理者：https://hoshilu.app/admin-login.html に本人の管理者認証でログイン後、https://hoshilu.app/admin/seller-candidates を開く。「掲載見本の相談受付」の保存3件を確認。通知状態・原文は認証内でのみ確認する。
- Resend：https://resend.com/emails で保存済みresend_idと配達・不達・苦情を照合、https://resend.com/domains で送信ドメイン設定を確認。API受付185件は配達185件ではない。APIキーをチャットに貼らない。

受信先を確認できた後、本人管理下の宛先だけでQA相談1件→受付番号→担当者通知→返信到着を確認し、テスト記録は獲得数から除外する。現時点で送信・受信確認は未実施。

## 操作（承認・migration適用後）
- 管理者：`/admin/seller-pilot` →「許諾済み商品で非公開見本を作る」。保存済みinquiry_id、事業者・外部関係確認の証跡、許諾済み3商品の情報を入力。
- 店舗本人：相談時メールで `/login.html` → `/seller-pilot`。見本と条件を確認→チェック→「掲載を承認」。GETや管理者代理では本人承認にならない。
- 管理者：「承認済み見本を公開」。その時点から3か月。
- 店舗本人：公開ページ確認後「店舗本人として掲載内容を確認しました」。この操作と許諾済み3商品・公開承認がそろって初めて獲得に計上。
