# 【本日から訴求の主役を変更】買う前に、まずホシル。日常の「同じものを安く買う」習慣へ

## 0. ユーザーの決定（2026-11-15）
> 普段の生活で欲しいもの、特に型番・品番まで決まっている商品を、モールを回ってログイン・検索して比較するのが面倒。同じ商品なら少しでも安く買いたい人、主婦や節約家が対象。日用品・家電・靴・化粧品・食品を中心に、13モールという固定枠にこだわらず販売先・メーカー直販も取り込む。日常的に「ホシルで検索 → 比較 → 安い販売先へ行く」を当たり前にする。SNS・Google広告も今日からこの価値をメインに打ち出す。

**最優先の顧客体験（北極星）**：「買いたいものが決まっている→商品名/JAN/型番/品番を入れる→同一規格の信頼できる販売先を支払総額で比較→正しい商品ページへ1タップ→買う」。買うものが決まっていない場合は既存BUZZ・曖昧/写真検索・希望価格通知を補助導線として継続。大型リニューアルや既存サービス停止は指示していない。

**広告・SNSの主メッセージ**：「買う前に、まずホシル。」／「同じ商品なら、できるだけ安く。」／「型番・品番で検索。買うお店を比較して選べる。」。旧コピー「探さなくていい。ホシっといて。」は通知機能のコピーとして残す。社内で用途を分け、統一されたメイン訴求は上記にする。

## 1. 優先セグメントと利用場面
- **第一ターゲット**：家計を管理する人・主婦/主夫・節約志向・日用品の反復購入者（性別で対象を限定しない）。「同じなら安く買う」という行動で捉える。
- **カテゴリ**：①日用品（洗剤・シャンプー・紙用品の詰替/入り数）②家電（正確な型番・色・付属品・保証）③靴（メーカー品番＋サイズ＋カラー）④化粧品（色番・容量・正規/並行輸入品）⑤食品（容量・味・本数・賞味期限やセット・温度帯）。
- **検索意図の軸**：型番/JAN/品番を指定した「買う商品が決まっている人」を主役にする。曖昧・写真検索は新しい主価値を補う。最初からすべての商品・ブランド・ECサイトを網羅したかのような表示は禁じる。

## 2. Cowork統括の開発運用（既存作業を置換・重複しない）
1. 正本 `2026-11-14-cowork-cheapest-guide-plan.md` の P1〜P6、E と Codex C-0〜C-8／Claude Code P3 を維持。**精度が先、対象拡張は次**。C-1「楽天×Yahoo!正しい同一商品照合」、C-2色・容量・入り数の矛盾チェック、C-3根拠ある最安、C-5直リンクは従来どおり優先。11/15進行中の写真検索・レンズ改善と同じファイルを並行編集しない。Coworkが1つの優先順位表で管理。

4. **購入直結**：商品詳細URLが検証できた場合だけ直接リンク。モールの検索ページに飛ばす場合は「モールで再検索」と表示し、最安・商品在庫確認済みと誤認させない。アフィリエイト料・Seller掲載費用で純粋な価格順位を変えない。既存P0「検索完了→購入先併有」や v23 の計測定義を維持。

   - 取込方法は①公式API②正式提供フィード③許諾済み提携データ④Seller/メーカーの同意済み商品フィードの順で検証。価格・画像・在庫の利用、更新頻度、深い商品リンク、API制限、広告表示、料金、アフィリエイト可否、契約要否を販売先別に台帳化。
   - 「横断検索のリンクだけ」「直接商品ページあり」「価格・在庫取得もあり」「送料・総額確認済み」「比較成立」「提携/収益化済み」を**別の状態**として管理。検索リンクだけを出品/正式連携済みと呼ばない。規約不明のスクレイピング・無承認のAPI・契約・有料課金はしない。
   - Seller/メーカー向けには自社直販フィード登録・商品の同一性検証・在庫/価格更新・契約条件の作業案を整理。営業は既存の土日含む9〜18時枠、重複防止、停止先除外、上限を守る。現行Seller料金を勝手に変更しない。

## 3. SNS — 今日11/15から訴求を主役にする（Coworkの販促担当）
- Instagram/Threads/LINEなど**現在承認・接続・稼働が確認できた既存の発信先**で、次に公開する販促は「同じ型番の商品、買う前にホシルで比較」をメインに。#616旧素材はレビュー待ちのまま再生成・公開しない。X停止は継続。Threadsの復旧は投稿ID/日時/URLで確認できるまで仮定しない。
- 既存の予約・承認・素材・公開枠を先に点検。**本日既存の承認済み枠で差し替え可能なら実施**。予約済み素材や承認済み原稿の勝手な上書き/強制公開はしない。新規の未承認投稿・追加費用を発生させる必要があるなら承認境界を明記。実施した場合はアカウント名、post ID、公開日時、公開URL、対応した最終LPを記録。下書きやキュー登録を公開済みと呼ばない。
- 投稿の主題：①洗剤・シャンプーなど毎回買うもの②家電型番の比較③スニーカーの品番・サイズ④化粧品の色番⑤食品の同じ容量/セット数。「他店より○円安い」などの具体数値は同一商品の同時刻の実価格・送料根拠がない限り書かない。

## 4. Google広告 — 新方針に合わせた原稿を本日準備、配信可否は証拠で管理

- 運用前チェック：現在の広告アカウント、既存配信中/停止中キャンペーン、既存予算、変更権限、地域・キーワード、遷移先の表示と実機での機能整合を確認。**このチャットのWindsor.ai接続でGoogle Adsアカウントが見つかっていない**。Cowork側で別の既存接続があるか確認し、未接続なら配信したことにしない。新規広告費・キャンペーン・予算増額・契約はユーザーの承認が要る。文言切替は既存承認と予算の範囲だけで行う。
- 検索意図キーワード候補（実キーワード追加は権限/予算確認後）：`型番 価格比較`, `品番 最安 比較`, `同じ商品 安い店`, `家電 型番 安い`, `スニーカー 品番 比較`, `化粧品 品番 比較`, `日用品 価格比較`。広告の一致タイプ・除外KW・地域・入札は現アカウントを確認してから。
- RSA見出し案：`買う前に、まずホシル`、`同じ商品なら価格を比べよう`、`型番・品番から購入先を探す`、`家電も日用品も買う前に比較`。
