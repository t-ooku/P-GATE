## 1. 申込ボタンを押しても、入力欄が画面に出てこない（スマホ）
1. **どこで**: `/for-sellers`、iPhone 13 相当（390×664 の表示域）。PC 1280×800 でも同じ傾向
2. **何をしたら**: 一番上の「1,980円の掲載を相談する」を押す
3. **何が起きたか**: フォームの見出しに移るが、最初の入力欄（店舗名・会社名）は表示域の上端から **1,051px 下**（スマホ約 1.6 画面ぶん）、「内容を送信」は **1,687px 下**。
   間に「1,980円で始められること」「1→2→3 の流れ」「お支払い登録は不要です」「30日無料の条件文」が続く。
   さらに固定ヘッダー（高さ 66px、`position: sticky`）がフォームの見出しの上部に重なる（`#businessForm` の `scroll-margin-top` が 0）。PC は入力欄まで 856px。
4. **どうなってほしいか**: ボタンを押したら、最初の入力欄が画面内に見えていること。
   案: 申込ボタンの飛び先を最初の入力欄の直前にする／説明のまとまりは折りたたむかフォームの下へ／`scroll-margin-top` をヘッダーの高さ以上にする。
   **30日無料・カード登録・自動更新の条件文は消さずに、送信ボタンの近くに残す**（文言の変更ではなく位置の変更）。

## 2. 「AI販促担当を相談する」を押しても、1,980円の掲載の相談フォームになる
1. **どこで**: `/for-sellers` の料金欄（スマホで上から約 8,500px・9,000px の 2 つ。`data-seller-cta="pricing-light"`／`"pricing-standard"`）
2. **何をしたら**: 「AI販促担当を相談する」を押す
3. **何が起きたか**: 1,980円用と同じ `#businessForm` に移る。見出しは「自店の掲載見本を相談する」、説明は「月額1,980円の掲載プランで始められること」。
   どのプランの相談かを選ぶ欄が無く、`plan_interest` も送られない（`for-sellers.js` 193 行目は `data.get('plan_interest')` を読むが、フォームにその欄が無い）。
4. **どうなってほしいか**: AI販促のボタンから来た人は、Light／Standard のどちらの相談かが自動で入る（隠し欄で可）。
   相談一覧（`seller_business_inquiries.plan_interest`）でもプランが分かること。料金・条件の文言は変えない。

## 3. セラー向けの来訪数・フォーム開始数に、リンク先の自動取得が混ざっている
1. **どこで**: `growth_events` の `seller_landing_view`（30 日で 158 件）・`seller_cta_clicked`・`seller_form_started`
2. **何をしたら**: 上の §0 のとおり、Threads のセラー投稿の数分後に 2 件ずつ同時に来る記録がある
3. **何が起きたか**: 10/16 の #644（名乗らないリンク先取得を訪問に数えない）がセラー向けの記録にも効いているか、Cowork からは確認できない
4. **どうなってほしいか**: #644 と同じ基準がセラー向けの 3 つにも効いていることの確認（効いていなければ同じ基準に）。
   週次記録（月曜）の「`/for-sellers` 閲覧」を人の数に近い値で書けるようにしたい。

## 4. SNS のセラー向け本文が「体験開始は準備中」のまま（本番の LP は開始済みの表示）
1. **どこで**: `src/social-screens.mjs` の `SCREEN_POSTS.seller`（10/17 土 20:00 の Instagram から使われる）と、Threads のセラー向け定型文
2. **何をしたら**: 本番 LP（`/for-sellers`）と本文を見比べた
3. **何が起きたか**: 本番は `SELLER_PILOT_RECRUITMENT_VERIFIED` が 10/3 から有効で、LP からは「現在は体験開始の準備中です」が外れている。
   一方、SNS の本文には「（体験開始は準備中）」が残っている（`seller-marketing-guard` は未開始のときだけ「準備中」を求める作り）。
4. **どうなってほしいか**: SNS の本文と LP の表示をそろえる。**注意書きの文言の変更なので、大隆さんの確認を取ってから**（Cowork から大隆さんに選択式で聞く）。
