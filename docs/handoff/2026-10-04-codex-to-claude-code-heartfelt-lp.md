## 現状の問題

公開LPは正確だが、第一画面の直後から8段階の仕組み、需要説明、料金、重複説明が続く。読者が「自分の悩みだ」と感じる前に機能説明へ移るため、相談CTAまで読む負担が大きい。

## 第一画面の確定依頼文

- 小見出し: `HOSHILU SELLER`
- 見出し:
  - `売る仕事で、一日が終わる。`
  - `販促まで、ひとりで抱えなくていい。`
- 補足見出し: `今のお店に、AIの販促担当を。`
- 本文:
  - `受注、発送、問い合わせ。目の前のお客さまを大切にするほど、ブログやSNSは後回しになります。HOSHILUは、記事・SNS投稿文・商品ページの直し案を毎週用意します。お店は内容を確かめて、承認するだけです。`
- 主CTA: `まずは相談する` → `#businessForm`
- 副CTA: `毎週届くものを見る` → `#weekly`
- 料金の短い補足: `掲載 月額1,980円／Light 月額9,800円／Standard 月額19,800円（税込）`
- その下に1回だけ: `初回公開から30日間無料。開始前にカード登録と自動更新への同意が必要です。相談フォームの送信だけでは課金されません。`

## 本文の並び

1. 毎週届くもの
2. 「広告を止めたら、入口まで消えてしまう」への短い説明
3. 3プラン
4. 始め方3段
5. 掲載プランでできること（折りたたみ）
6. FAQ 5問
7. 相談フォーム

既存の8段階フロー、INCLUDED、SHOP、KPI、重複する課金説明は、正本のcopy-trim指示どおり削るか統合する。

## 表現の原則

- 店が怠けているように書かない。「目の前のお客さまを優先しているから後回しになる」と捉える。
- 「売上が上がる」「集客できる」と断定しない。
- QA店舗、内部店舗、架空成果を実績として使わない。
- AIの便利さより、店の時間が戻り、販促が止まらない価値を先に伝える。
- 和文と英数の間の不要な半角スペースを削る。
- 360〜430pxで横はみ出しなし、語の途中の不自然な改行なし。

## 成功条件

公開したことではなく、`seller_landing_view → seller_cta_clicked → form_start → inquiry_success` をプラン別に追えること。母数が少ない間は勝敗を断定しない。
