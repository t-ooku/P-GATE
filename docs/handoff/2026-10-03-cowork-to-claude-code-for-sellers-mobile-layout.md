# Cowork → Claude Code 依頼｜`/for-sellers` スマホ表示の崩れ（2026-10-03 夜）

発行: Cowork（Claude）。根拠: 大隆さんの iPhone（Safari・幅 390px 相当）のスクリーンショット 2枚（料金欄・第一画面の下）。
指摘: 改行位置とはみ出し。文言の意味・料金・条件は変えない（直すのは表示と区切りだけ）。

## 1. 見えている症状

1. **ページ全体が横にはみ出している**: ヘッダーと背景の右端が画面幅より手前で切れ、右に白い帯が出る（= `document.scrollWidth > innerWidth`）。料金欄の黒いカードも右端が画面の外に出ている。
2. **料金欄の見出し**「掲載だけなら1,980円。／販促まで任せるなら、AI販促担当。」の2行目が画面の右端からはみ出す。文字が大きすぎる。
3. 見出し・本文の上を **縦の線（枠線）が横切る**（料金欄の枠より文字が右へ出ている）。
4. **ピンクの注意書き**（30日無料・自動課金）が角丸の大きい「錠剤型」で、最後の行「えます。」が丸い角に食い込む。
5. 第一画面下の料金の行が **「Standard 月／額19,800円」と語の途中で改行**する。「自動更新へ／の同意」も途中で切れる。
6. **ボタンの幅がそろっていない**（「AI販促担当を相談する」が短く、「料金を見る」が長い）。
7. 和文の中に **半角スペース**が入っている（「AI の販促担当」「Google 検索」「SNS の投稿文」「HOSHILU 内の」）。Cowork の文案が原因。和文と英数の間のスペースは削除する。

## 2. 直し方（既定。より良い方法があればそちらで）

1. はみ出しの犯人を特定する（幅を固定している要素・`100vw`・負のマージン・`white-space:nowrap` の長い見出し）。`html,body{overflow-x:clip}` で隠すだけで終わらせず、原因の要素を直す。`box-sizing:border-box`、画像・カードは `max-width:100%`。
2. 見出しは `font-size: clamp(…)` で幅に合わせて縮め、句の途中で切れないように区切る。Safari は `word-break: auto-phrase` 非対応なので、見出し・料金行は句ごとに `<span style="display:inline-block">` で包む（例:「販促まで任せるなら、」「AI販促担当。」）。本文は `line-break: strict` と `overflow-wrap: anywhere`。
3. 料金の行は2行に分ける:
   - Light 月額9,800円（税込）
   - Standard 月額19,800円（税込）
   - HOSHILU内の掲載だけなら月額1,980円（税込）
4. 注意書きの角丸は 16px 程度に（錠剤型にしない）。内側の余白を上下左右そろえる。
5. スマホ幅ではボタンを全幅・同じ高さにそろえる。
6. 和文と英数の間の半角スペースを削除（公開 LP・preview・記事の文言すべて）。
