## 0. 返信の分類と次の一手

| 店の返信 | 分類 | 次の一手 |
|---|---|---|
| 興味がある・試したい | A | 型 A-1 を送る → 4点がそろったら Claude Code に登録依頼（§E）→ 返ってきたら型 A-2 を送る |
| 質問がある | B | 型 B の該当項目で答える。答えが無い質問は大隆さんに選択式で聞く |
| 「不要」・お断り | C | 型 C（任意）。Claude Code に hash で送信停止の記録を依頼 |
| 値引きの相談 | D | 型 D。値引き・特例は大隆さんの判断 |
| 返信なし | — | 追いかけない（1アドレス1回）。7日で「返信なし」と記録 |

**ログインに使うメールアドレス＝店が返信してきたアドレス**（相談はこのアドレスで作る）。担当者が別のアドレスを使いたい場合は、そのアドレスから一度返信してもらう。

## B. よくある質問への答え

- **売上は増えますか** — お約束はできません。作ったもの・公開したもの・数字を毎月そのままご報告します。Google からの流入は効果が出るまで数か月かかることが多いです。
- **手間はどれくらい？** — 最初に4点を送っていただくだけです。毎週月曜に届いたものを確認して「承認」を押していただきます（数分）。慣れたら自動公開にもできます。
- **AI が間違ったことを書かない？** — お店の商品データにない数字（価格・寸法など）は書かない仕組みで、禁止表現も機械で検査しています。公開前に必ずお店で確認いただき、気になる表現は「差し戻し」で直せます。
- **楽天・Amazon の規約は大丈夫？** — 公開先はお店のサイト・楽天GOLD・SNS で、モールの商品ページを勝手に書き換えることはありません。商品ページの直し案は、お店が貼り付けるかどうかを決めます。
- **データの扱いは？** — お預かりするのは商品情報・ロゴ・お店が教えてくださった質問の要約だけです。お客さまの個人情報・注文情報・レビュー原文は受け取りません。WordPress のパスワードは暗号化して保存し、画面にもメールにも出しません。
- **SNS に自動で投稿される？** — いいえ。投稿文と画像をお届けし、投稿はお店で行っていただきます（自動投稿は準備中）。
- **解約は？** — 管理画面からいつでもできます。30日の無料期間中なら費用はかかりません。公開した記事はお店のものとして残ります。
- **化粧品・食品は？** — 現在は対象外です（表示ルールの確認が重いため）。生活雑貨・インテリア・ペット・文具・アウトドア・バッグ・靴が対象です。
- **Shopify は？** — 自動公開は未対応です。原稿の受け取り（Light）なら使えます。

## E. 登録の依頼を Claude Code に出すとき（ひな形）

ファイル: `docs/handoff/YYYY-MM-DD-cowork-to-claude-code-ai-promo-store-N.md`

- 店の識別: `store-N`（店名は書かない）。案内候補の番号（C1〜C6）を併記
- 相談（inquiry）: 返信メールを根拠に作る（依頼書 §8・既定 a）。メールアドレスは大隆さん経由で渡す
- plan: LIGHT／STANDARD
- categories・ng_words・brand.color・publish_target・weekday（既定 月）・hour_jst（既定 6）
- 商品: 件数と列の説明（CSV の中身・URL はリポジトリに置かず、大隆さん経由で渡す）
- 疑問: 件数（本文は渡し方を別にする）
- 頼むこと: 相談作成 → 掲載契約 CREATE（plan 付き）→ AI販促プロファイル（`seller_key: pilot-<pilot_id>`・`pilot_id`・同じ plan）→ 商品・疑問 → 「A-2 を送ってよい」と progress に。店の同意・カード登録の後に初回 run
