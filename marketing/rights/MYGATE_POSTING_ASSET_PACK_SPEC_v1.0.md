# MYGATE投稿素材パック仕様 v1.0

## 1. 適用範囲

この素材パックは任意であり、全セラーへ提出を要求しない。提供できた商品だけがMYGATE公式の商品投稿候補になる。

提供できない商品は、セラー自身のSNSで宣伝し、MYGATEは投稿支援と計測導線を提供する。

## 2. 最小パック

セラー・メーカーは、最低限次を提供する。

- 縦動画1本、または権利者が撮影した商品写真3枚以上
- 商品名、ブランド名、特徴3点
- 使用上の注意と誤認防止情報
- 正式な販売URL
- 素材の権利者名
- MYGATEによる編集、字幕、トリミング、SNS投稿の許可
- 許可する媒体、地域、期間、有料広告への利用可否

## 3. 権利確認項目

| 項目 | 必須 |
|---|---|
| 素材提供者が権利者または正規の許諾者である | 必須 |
| MYGATE公式SNSでの掲載 | 必須 |
| トリミング、字幕、BGM、短尺動画化 | 必須 |
| ECリンクへの送客 | 必須 |
| 掲載期間 | 必須 |
| 有料広告への転用 | 任意・別同意 |
| 二次配布・第三者提供 | 原則不可 |

## 4. 証跡管理フィールド

`asset_pack_id, seller_id, product_id, rights_holder, source_type, channels, edit_allowed, paid_ads_allowed, territory, valid_from, valid_until, evidence_url, approved_by, approved_at, status`

状態は `DRAFT / REVIEW / APPROVED / EXPIRED / REVOKED` とする。`APPROVED` 以外の素材は公開キューへ送らない。

## 5. 提供者確認文

> 私は、本素材を提供し、指定した期間・媒体・地域の範囲で、MYGATEが編集、字幕付与、短尺動画化、SNS掲載および販売ページへの送客に利用する権限を有することを確認します。第三者の権利を侵害する素材を含めません。有料広告利用は、別途明示的に同意した場合に限ります。
