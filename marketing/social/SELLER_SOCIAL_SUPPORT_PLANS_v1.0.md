# セラーSNS投稿支援 v1.0

## 1. 位置づけ

`MYGATE投稿素材パック` を提供できない商品の宣伝は、セラー自身のSNSアカウントで行う。MYGATEは契約プランに応じて投稿制作・運用を支援する。

セラーが自ら保有する画像・動画を自分のアカウントで使用するため、MYGATE公式への素材権利移転を前提にしない。

## 2. プラン別支援

| 支援内容 | Lite | Growth | Pro | Partner |
|---|---:|---:|---:|---:|
| 投稿テーマ提案 | 月1 | 月4 | 月12 | 月20 |
| 投稿文・ハッシュタグ | テンプレ | 作成 | 最適化 | 個別運用 |
| 短尺動画台本 | - | 月2 | 月8 | 月16 |
| セラー素材の編集 | - | - | 月4 | 月12 |
| 予約投稿設定支援 | - | 手順提供 | 対応 | 対応 |
| MYGATE商品ページ導線 | 基本 | 基本 | 最適化 | 優先 |
| UTM・効果測定 | 月次概要 | 月次 | 週次 | 週次＋改善会議 |
| MYGATE公式への掲載審査 | - | 素材パック時 | 素材パック時 | 優先審査 |

投稿回数と作業範囲は原価測定後に確定する。無制限対応は行わない。

## 3. セラー投稿の標準導線

セラーSNS投稿 → MYGATE商品詳細・相談ページ → セラーEC

直接ECへ送る選択肢も残すが、MYGATEを経由する場合は次が可能になる。

- 商品名が分からないユーザーへの追加説明
- 互換性・用途の確認
- MYWISH保存
- MYWATCH通知
- 投稿別の送客計測

## 4. セラー向け投稿テンプレート

### 問題解決型

> 「こういうものが欲しいけれど、名前が分からない」という声から選びました。用途や条件をMYGATEで相談できます。
> [MYGATE URL + UTM]
> #PR #MYGATE

### 海外商品型

> アメリカで見つけたこの商品、日本で使う前に確認したい条件をMYGATEで整理できます。販売条件・仕様はリンク先で最新情報をご確認ください。
> [MYGATE URL + UTM]

### 再入荷・値下げ型

> 気になっていた商品が入荷しました。次回の入荷・値下げを待ちたい場合はMYWISHへ。
> [MYGATE URL + UTM]

## 5. 表示ルール

- 広告、アフィリエイト、提供、タイアップに該当する場合は、媒体ルールに従い明瞭に表示する。
- 価格、在庫、配送、適合は投稿内で固定せず、最新販売ページの確認を促す。
- セラーが権利を保有しない第三者素材をMYGATEへ編集依頼しない。
