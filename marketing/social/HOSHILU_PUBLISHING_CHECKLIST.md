# HOSHILU SNS投稿前チェック

各投稿は公開担当と承認担当の二者で確認する。

- [ ] ブランド名がHOSHILU／ホシルで統一されている
- [ ] 商品画像・動画は権利記録がAPPROVED
- [ ] 権利不明なら商品を再現せず、課題・検索体験の投稿にする
- [ ] コメント集計を行う投稿には匿名集計の告知がある
- [ ] 原コメントを引用する場合は別途掲載許可がある
- [ ] 個人情報、健康断定、安全断定、価格・在庫断定がない
- [ ] `campaign`、`utm_source`、`utm_content`付きHOSHILUリンクを使用
- [ ] リンク先で投稿テーマが検索窓へ引き継がれる
- [ ] PR・提供・広告関係がある場合は明示する
- [ ] 緊急停止担当、問い合わせ担当、公開日時を記録する

投稿後24時間・7日で、表示、保存、共有、コメント、サイト流入、検索開始、
検索完了、ほしっトクを記録する。低実績投稿は削除せず、冒頭・CTA・尺を変えて再検証する。
