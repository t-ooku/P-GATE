# HOSHILU 新検索ローンチ販促設計 — 2026-08-29

## 目的

写真・保存画像・スクリーンショット・公開SNS投稿URL・一言から探せる現在のHOSHILUを、ひとつの体験として伝える。検索直後に候補がなくても「見つかるまで探す」へつなぎ、検索開始、購入先送客、無料登録、通知再訪を増やす。

Amazon API接続と広告主提携は別スレッドのため、この施策には含めない。

## 統一メッセージ

- 主見出し：`その「欲しい」、撮ってホシル。`
- 補助見出し：`名前がわからなくても、写真が手がかりになる。`
- 継続検索：`見つからなくても、終わりじゃない。`
- CTA：`カメラで探してみる`
- 継続CTA：`無料会員で継続検索を有効にする`

## 正確に伝える機能

| 機能 | 使用する説明 |
|---|---|
| カメラ・画像 | AIが写真の色・形などの特徴理解を補助し、HOSHILUが購入先候補を探す |
| 公開投稿URL | Instagram、TikTok、X、Threads、Facebook、Pinterestで、各サービスのHOSHILU対応形式に合う公開投稿単体URLを手がかりにできる |
| 一言 | 商品名が不明でも、見た場所・色・形・用途などから検索語と候補を整理する |
| 見つかるまで探す | 条件を定期的に検索し、新しく一致する実在商品が見つかった時だけ知らせる。値下げ通知とは別 |
| HOSHILU BUZZ | 楽天市場・Yahoo!ショッピングの公式ランキングと順位変化を根拠にした棚。SNS指標では並べない |

写真・画像・投稿URLはHOSHILUに保存しない。商品特定の補助にGoogle Cloud VisionのWeb画像照合とGoogle Gemini APIを使う場合がある。顔・住所・伝票などを写さないよう案内する。

## 計測

新検索投稿は `utm_campaign=hoshilu-new-search-launch-20260829` で旧13モール施策と分離する。
ただしInstagramの通常投稿本文ではキャンペーンURLをクリックできないため、
実際のプロフィールURLを同じUTMへ更新した証跡がない限り、投稿別クリックとしては集計しない。
Instagramは公開済みパーマリンクに紐づくリーチ・保存・プロフィール訪問のネイティブ指標で判定する。
日次AI女優Reelは素材台帳と週次シリーズの同一性を保つため、既存の
`hoshilu-ai-actress-daily-v1`で計測し、曜日・配信日で新機能枠を判別する。

主ファネル：

`SNS／自然検索 → ガイド・トップ → 入力選択 → 検索完了 → 商品候補 → モール送客`

継続ファネル：

`検索 → 見つかるまで探す保存 → 無料登録 → 継続検索を明示的に有効化 → 新規一致通知 → 再訪 → モール送客`

入力モード、検索完了、送客、`continuous_search_saved`（条件保存）、
`continuous_search_enabled`（会員DBへの通知条件保存成功）を分けて集計する。
検索文、画像、投稿URLの生値は分析イベントへ保存しない。

年間100万流入は、販促ダッシュボードと同じQA除外済みの匿名ユニーク訪問者で管理する。必要平均は月83,333人、日2,740人。

## 公開・QAガード

- 受け入れ確認URLには `utm_source=codex_qa&utm_medium=qa&utm_campaign=acceptance_search` を付け、実ユーザーKPIから除外する
- Cloud Visionのアプリ側月次上限は900画像。上限時は画像なしの一言検索・公開投稿URL・継続検索へ戻せる案内を維持する
- 実ユーザーの検索成功率とTurnstile失敗を監視し、障害時は結果保証型の投稿を止める
- 商品画像・SNS投稿・口コミ・ブランドロゴは、権利確認済み素材だけを使う
