# HOSHILU SNS外グロース実行計画（2026-08-01）

## 実施境界

SNS投稿・SNS運用・SNS用素材には触れない。広告出稿、契約、外部アカウント作成、媒体申請、外部送信、公開、個人情報利用は承認後に本人が実行する。未確認の実績・価格・セール・提携を表示しない。

## 現状監査

- 本番 `https://hoshilu.app/`、`robots.txt`、`sitemap.xml` は 2026-08-01 に HTTP 200 を確認。
- 日英5テーマ（10 URL）のSEOページ、canonical、hreflang、サイトマップ、FAQ、トップの WebSite / WebApplication 構造化データは実装済み。
- 匿名の `landing_view`、`search_started`、`search_completed`、`wish_saved`、`marketplace_click` は実装済み。QAは `traffic_class=QA` に分離済み。
- 無料登録、再訪、PWAインストール、SEOページ経由検索の計測が欠落し、登録ページ遷移時に流入情報が切れていた。本変更で補完する。
- 商品名不明、特徴検索、海外商品、日本在住者、商品リクエストの検索意図は既存ページがカバー。類似ページの量産より、品質・内部導線・実測を優先する。

## 優先順位

### P0: 計測の信頼性（実装対象）

1. `registration_started` / `registration_completed` を認証方式別に匿名記録。
2. 30分以上空いた訪問を `return_visit` として記録。
3. `pwa_install_prompted` / `pwa_install_completed` を記録。
4. UTMを同一タブ内で登録ページまで引き継ぐ。メール、検索文、会員IDは送らない。
5. SEOページの検索フォームも `search_started` に含める。
6. 集計時は必ず `traffic_class != 'QA'` を実績値、`traffic_class = 'QA'` を検証値として別表にする。

### P1: SEOとCRO（実装対象）

1. SEOページに WebPage 構造化データ、OG基本情報、匿名計測、無料登録導線を追加。
2. Search Consoleでサイトマップ送信、URL検査、指名・非指名クエリを分離（外部操作のため承認待ち）。
3. 実測が100セッション以上たまるまで新規SEOページを量産しない。検索開始率が低いページからタイトル、冒頭文、CTAを改善する。

### P2: 検索広告・リターゲティング（設計のみ）

- 検索広告は「商品名が分からない」「特徴から商品を探す」「海外商品 日本で買う」の3広告グループから開始。
- 競合商標のキーワード挿入・広告文利用はしない。除外語は「求人」「中古 買取」「違法」「偽物」「無料配布」。
- 初期試験案: 14日、1日1,500円、上限21,000円。一次KPIは非QAの検索開始、二次KPIは検索完了・無料登録・モール送客。広告クリック数だけで判断しない。
- リターゲティングは同意管理とプライバシーポリシー更新を完了してから。個人情報・検索文によるオーディエンス作成は禁止。

### P3: 獲得チャネル準備

- プレス: サービス事実、対応モール、無料利用、商品名不明でも特徴から探せる点だけを記載。未確認の利用者数・精度・No.1表現は使わない。
- 無料掲載枠・ディレクトリ: 運営者情報、ロゴ利用権、リンク属性、掲載更新・削除方法を確認して個別申請。
- 提携: 販売店・ブランド・在日外国人支援媒体・買い物支援メディアへ、成果報酬または共同記事を個別提案。提供価値と広告表記を明示。
- 被リンク: 独自データを公開できる段階で、匿名集計の「名前が分からない商品検索トレンド」を編集者向けに提供。少数データやQA流入を実績化しない。
- オフライン: QRコード付きA6カードを店頭・イベント向けに用意。設置許可を得た場所だけで配布する。

## KPI定義

| 目的 | 指標 | イベント/外部データ | 分母 |
|---|---|---|---|
| 自然検索流入 | Organic clicks | Search Console | 検索表示回数 |
| 指名検索 | `HOSHILU` / `ホシル` query clicks | Search Console | 指名表示回数 |
| LP到達 | `landing_view` | growth_events | チャネル別 |
| 横断検索利用 | `search_started`, `search_completed` | growth_events | LP到達 |
| 無料登録 | `registration_completed` | growth_events | 登録開始 / LP到達 |
| 再訪 | `return_visit` | growth_events | 匿名訪問 |
| モール送客 | `marketplace_click` | growth_events | 検索完了 |

全指標で `traffic_class` を維持し、QAを合算しない。指名検索はSearch Consoleのquery単位、LP以降はUTM/流入分類単位で評価し、推定で接続しない。

## 承認後の実行順

1. Search Console所有権確認とサイトマップ送信（費用0円）。
2. 計測変更を本番反映し、QA UTMで一連のイベントを確認（実績から除外）。
3. 2週間の自然流入ベースライン取得。
4. 検索広告の21,000円上限試験を承認後に開始。
5. 100セッション/ページまたは4週間の早い方でCRO判定。
