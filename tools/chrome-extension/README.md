# ホシル Chrome拡張 v0.4

表示中の商品ページのタイトル、または利用者が選択した文字だけを読み取り、
ホシルの会話画面へ引き継ぐManifest V3拡張です。

## 利用方法

1. Chromeの「拡張機能を管理」を開く。
2. デベロッパーモードを有効化する。
3. 「パッケージ化されていない拡張機能を読み込む」から本フォルダーを選ぶ。
4. 拡張の設定画面で、公開済みホシルのHTTPS URLを登録する。
5. 商品ページでホシルのアイコンを押し、相談内容を確認して同意する。

## プライバシーと権限

- `activeTab`: 利用者がホシルを開いた現在のタブだけに限定。
- `scripting`: 現在タブのタイトルと選択文字だけを取得。
- `sidePanel`: ホシルへの相談画面を表示。
- `storage`: 公開済みホシルの接続先URLだけを保存。

閲覧履歴、Cookie、入力フォーム、ページ本文全体は取得しません。質問はクエリ文字列ではなく
URLフラグメントで渡し、通常のHTTPアクセスログへ含めません。

## Brand migration

v0.3.0で公開表示をMYGATEからホシル／HOSHILUへ変更しました。保存済み接続先URLは維持されます。


v0.4.0でChromeに表示される名称・説明・アクション名を日本語、英語、中国語、韓国語へローカライズしました。
