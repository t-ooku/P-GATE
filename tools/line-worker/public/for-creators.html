POSTING RULES

報酬対象になる投稿の条件

「適当な投稿」を防ぐため、次の条件をすべて満たした投稿だけを承認します。1つでも欠けると報酬対象外です（修正して再報告は可能）。

項目条件
広告表記本文の先頭付近に #PR と #ホシル を明記（景品表示法のステルスマーケティング規制に対応）。
実際に使うHOSHILUで実際に検索した画面（スクリーンショットまたは画面録画）を最低1枚／1カット含める。素材だけの転載は不可。
機能を正しく伝える「希望価格になったら通知」「クーポン・セール通知」「13モールまとめて検索」のうち1つ以上を、素材の訴求ポイントの表現で説明する。「最安保証」「必ず安くなる」など事実でない表現は不可。
計測リンク応募承認時にお渡しするあなた専用URLを本文またはプロフィールリンクに掲載（Instagramはプロフィール可）。URLの改変不可。
分量Instagram: 画像3枚以上またはリール15秒以上、本文150文字以上。X: 画像1枚以上または動画、本文60文字以上。TikTok: 15秒以上。
公開状態公開アカウント・公開投稿のみ。限定公開、親しい友達、24時間で消える形式は対象外。
頻度同一媒体で1日1投稿まで。同じ内容・同じ素材の使い回しは、素材の組み合わせを変えても月2回まで。
禁止事項他社サービスの誹謗、虚偽の割引率・価格、医療・効能の断定、フォロワー・いいねの購入、自動投稿ツール、投稿後の無断削除、当社素材の改変（トリミング・文字入れは可、ロゴの変形・色変更は不可）、AI生成素材を実写と誤認させる表現（AI女優素材には「AI生成」を明記）。
二次利用投稿した画像・動画は、当社のPRツール・広告・WEBページで永久に二次利用します。担当者から元データの送付依頼があった場合は、指定の方法で完了報告の承認前に送ってください。取引完了後の削除・利用停止の依頼は原則できません。
報告投稿から7日以内に下のフォーム（種別「投稿の報告」）から投稿URLを送る。当社は5営業日以内に承認・差し戻しをメールで通知します。

HOW IT WORKS

応募から支払いまで。

  1. 1
    応募フォームから媒体・アカウントURLを送信。3営業日以内にメールで結果をお知らせします。
  2. 2
    専用URL発行承認された方に、あなた専用の計測URLと素材の使い方をメールでお渡しします。
  3. 3
    投稿・報告ルールに沿って投稿し、7日以内に投稿URLを報告。
  4. 4
    承認・請求承認日を基準に月末締め。翌月5日までに請求書（PDF可）をメールで送ってください。
  5. 5
    お支払い翌月末までに指定口座へ振込。

KEY MESSAGES / USER

ユーザー向け 訴求ポイント（コピペ可）

  • 探さなくていい。ホシっといて。見つからなければ、HOSHILUが見つかるまで探します。
  • 「この価格になったら教えて」を押すだけ。希望価格になったらHOSHILUが知らせます（値下がり待ち）。
  • 欲しいものを、全ショップから探す。「黒の本革で自立するA4トート」のように条件で。
  • Amazon・楽天・Qoo10・SHEINなど、今ある販売先の商品をまとめて探せる。
  • 商品名が分からなくても、見た目・用途・写真から探せる。

数字（◯%OFF・最安）は、モールが公式に出している時だけ、その表記どおりに。「必ず見つかる」「100%」は書かないでください。

KEY MESSAGES / SELLER

セラー向け 訴求ポイント（特にお願いしたい）

  • 欲しい人が、先に見える。HOSHILUで探して見つからなかった「欲しい」が、匿名の需要としてお店に届く。
  • 商品を出したら、探していた人へHOSHILUが届ける。Amazon・楽天・Yahoo!など今ある販売先はそのまま。
  • HOSHILU Seller 月額4,980円（税込）、最初の3か月は月額0円。初期費用0円。
  • 探していた人を呼び戻せた時だけ Demand Match Click 50円。通常のクリックは月額に含まれる。
  • 申込みは hoshilu.app/for-sellers（相談フォーム送信だけでは課金されない）。

売上・注文・掲載順位の保証、「多数のセラーが参加」など実績にないことは書かないでください。
