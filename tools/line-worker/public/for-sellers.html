01

02

買い時までつなぐ

「○円なら買う」の希望価格ウォッチ、セール通知、クーポン、ショップをホシる（フォロー）。今すぐ買わない人を、将来の購入候補として残せます。

03

数字で見る

フォロー数、ショップページの閲覧、有効クーポン、送客クリックを契約者画面で確認。実数だけを表示し、推定値は出しません。

3 WAYS TO BE FOUND

商品・ジャンル・ショップ、
3方向から見つかる。

01 商品で探す

「本革トート」と探した人に

検索結果の商品カードに「この商品を扱うショップ」とHOSHILU限定クーポンが並びます。商品を見た人が、そのままショップへ。

02 ジャンルで探す

ファッション → バッグ → トート

ジャンルのランキングから掘り下げた先で、商品とショップに出会います。強いジャンルのショップ表示は準備中です。

03 ショップで探す

「ショップから探す」ボタン

トップの「ショップから探す」から、クーポン・ひとこと・商品一覧つきのショップページへ。Amazonのショップページへの導線も付きます。

COUPON

クーポンは、あなたが発行。

10%OFF、500円OFF、送料無料、新規限定、フォロワー限定、商品限定、期間限定。原資はセラー、HOSHILUは割引を負担しません。商品カードと検索結果に「🎟」で表示されます。

FOLLOW

♡ このショップをホシる

一度来た人が、セール・クーポン・新商品・キャンペーンの通知を受け取る側になります。リピーター候補を、ショップ単位で積み上げられます。

WATCH SET / SALE ALERT

「今は買わない」を、
捨てない。

希望価格ウォッチ

商品を見た人が「この価格になったら教えて」と登録 → 条件成立 → 通知 → モールへクリック。商品を見ても今すぐ買わない人を、将来の購入へつなげます。

セール通知

ユーザーはモールとセールの種類を選んで通知を受け取ります。あなたのセール・クーポンの開始が、待っている人に届きます。

買った後の値下がり通知

買った値段より安くなったら30日間だけ知らせる「逆ウォッチ」。買った後も、ショップとの接点が続きます。

REAL DEMAND

売る前に、
欲しいが見える。

値下げ通知に登録された商品条件と、HOSHILUで見つからなかった需要。その声を、次の仕入れ・商品開発・価格判断に使える形で届けます。「この検索需要は高いが、あなたの露出は少ない」という機会損失の提示は準備中です。

PRICE WISH

この価格なら、欲しい。

商品ごとの希望価格帯と、値下げを待つ匿名ユーザー数を集計します。

UNMET SEARCH

探したけど、なかった。

見つからなかった商品のカテゴリ・属性を集計し、取りこぼしている需要を可視化します。

検索文そのものや個人情報は共有しません。匿名需要が5件以上集まった項目だけをBusinessで表示します。

KPI

見られた。クリックされた。
ホシられた。

契約者画面で今見られるもの: ショップのフォロー数・30日のショップ閲覧・有効クーポン数・送客クリックと消化状況・優先掲載の状況。準備中: Watch Set数、クーポン利用、検索需要との突き合わせ、Creator流入。実数だけを表示し、推定値や「見込み」は出しません。

INFLUENCER

フォロワー数ではなく、
流入とクリックで見る。
